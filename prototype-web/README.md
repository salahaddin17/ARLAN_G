# РУБЕЖ: АРЛАН

Играбельный прототип стратегии в реальном времени в стилистике «штабной карты»:
бумажно-песчаный степной террейн с изолиниями, юниты — тактические фишки с
чернильной обводкой, тёмная HUD-консоль. Vite + TypeScript, Canvas 2D, без
игровых движков и внешних ассетов.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest: A*, матрица урона, интеграционная партия
npm run build    # typecheck + прод-сборка
```

Отладка баланса: `?speed=8` в адресе ускоряет симуляцию (1..16).

## Геймплей

- **Фракции**: «Легион» (teal, +15% цена и прочность) и «Вольный фронт»
  (orange, −15% цены, −10% прочности, +10% скорости). Выбор в меню.
- **Экономика**: грузовики возят припасы со складов на карте в командный
  центр. Энергостанции дают энергию; при дефиците производство ×0.5.
- **Здания**: командный центр, энергостанция, казармы, завод техники, турель.
  Строит техник: меню → размещение призрака → стройка со временем.
- **Юниты**: техник, грузовик, пехотинец, ракетчик, разведмашина, танк,
  артиллерия (сплеш, минимальная дальность).
- **Баланс** — матрица «тип урона × тип брони»
  (bullet/rocket/shell/defense × INF/LGT/HVY/BLD): пули косят пехоту,
  ракеты жгут броню, снаряды ломают здания, турели сдерживают, но не штурмуют.
- **Туман войны** двухуровневый: неразведанное / разведанное (память о
  зданиях) / видимое.
- **ИИ**: билд-ордер, собственная экономика грузовиками, турели к фронту,
  оборона базы, волны атак нарастающей силы; сложности Рекрут/Ветеран/Комиссар.
  Первая стычка — на 3–5 минуте.
- **Победа** — снос всех зданий противника; финальный экран со штампом
  ПОБЕДА/РАЗГРОМ и статистикой операции.

## Управление

| Действие | Ввод |
| --- | --- |
| Выделение | ЛКМ-рамка, клик; Shift — добавить |
| Приказ (движение/атака/сбор/ремонт) | ПКМ по контексту |
| Атака-движение | `A`, затем ЛКМ |
| Стоп | `S` |
| Группы | `Ctrl+1..9` назначить, `1..9` выбрать (повторно — камера) |
| Камера | WASD / стрелки / края экрана, колесо — зум |
| Миникарта | ЛКМ — перенос камеры (с перетаскиванием) |
| Производство/стройка | кнопки HUD или `Q W E R T` |
| Точка сбора | ПКМ при выделенном здании |

## Архитектура

```
src/
  data/balance.ts   — все таблицы: юниты, здания, матрица урона, фракции, сложности
  sim/              — симуляция, фиксированный тик 20 Гц, без DOM
    grid.ts         — сетка 64×64, генерация карты (шум, скалы, склады)
    pathfinding.ts  — A* (бинарная куча, октильная эвристика, без срезания углов)
    world.ts        — состояние мира, сущности, спавн
    sim.ts          — приказы, движение, бой, экономика, стройка, победа
    fog.ts          — туман войны
  ai/ai.ts          — ИИ-противник (только через публичные приказы симуляции)
  render/           — камера, запечённый террейн (marching squares), отрисовка
  input/input.ts    — мышь, клавиатура, камера, группы, размещение зданий
  ui/               — HUD-консоль (canvas) и DOM-экраны меню/финала
tests/              — A*, матрица урона, интеграционная headless-партия
```

Симуляция полностью отделена от отрисовки: `sim/` и `ai/` не знают о canvas
и DOM, что позволяет прогонять целые партии в тестах (`tests/integration.test.ts`).
